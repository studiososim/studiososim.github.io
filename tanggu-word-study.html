Support & Privacy Policy

Effective: September 11, 2026

App support

Tanggu Word Study is an offline vocabulary-learning app with daily 20-word sessions, pronunciation, favorites, and missed-word review. If you need help, email studiososim@gmail.com.

1. Information stored on the device

The selected learning level, daily word set, study progress, answer counts, favorites, missed words, sound setting, and word-list position are stored locally on the device. They are used only to provide and continue the app's learning features.

2. Information we do not collect

The current version has no registration, login, online account, analytics SDK, advertising SDK, advertising, or in-app purchases. Studio Sosim does not receive or store a name, email address, phone number, postal address, contacts, photos, precise location, advertising identifier, study history, or device-local settings from the app.

3. Network use and pronunciation

The vocabulary data, meanings, images, interface, and learning functions are bundled with the app and work without an internet connection. English pronunciation uses a system voice installed on the device, so offline pronunciation can be limited when an English voice is unavailable. Opening this privacy page, a source page, a license page on the web, or an email link requires a network connection and is performed only after the user selects the link.

4. Retention and deletion

Local learning data remains on the device until the user resets all study progress, clears the app's stored data, or removes the app. Device backups may retain a copy according to the user's operating-system and backup settings. Studio Sosim cannot remotely view, restore, or delete this local data because it is not held on a Studio Sosim server.

5. Tracking, sales, and sharing

The app does not track users across other companies' apps or websites. Studio Sosim does not sell or share personal information from the app. The public policy website is hosted with GitHub Pages; GitHub may process ordinary web request information under its own privacy statement when the page is visited.

6. Children and security

The app does not ask children or other users to submit contact or account information. Parents or guardians should supervise device use where appropriate. Data processing is minimized by keeping learning records on the device.

7. Dictionaries, graphics, licenses, and contact

The app contains open-licensed dictionary materials. Source, attribution, modification, share-alike, Godot Engine, font, and asset notices are provided in the app's Open Licenses and Sources screen. Tanggu is an original Studio Sosim character. Some graphics were generated or refined with AI-assisted tools using Studio Sosim-provided references, then selected and edited by Studio Sosim.

8. Policy changes

This policy may be updated if the app's features, data practices, services, or legal requirements change. The latest effective date and current policy will be posted on this page.

앱 지원

탱구 영단어는 하루 20단어 학습, 영어 발음, 즐겨찾기와 오답 복습을 제공하는 오프라인 단어 학습 앱입니다. 도움이 필요하면 studiososim@gmail.com으로 문의해 주세요.

1. 기기에 저장되는 정보

선택한 학습 단계, 오늘의 단어 묶음, 학습 진행, 정답·오답 횟수, 즐겨찾기, 틀린 단어, 효과음 설정과 단어 목록 위치는 이용자의 기기 내부에 저장됩니다. 이 정보는 앱의 학습 기능을 제공하고 이어서 학습하기 위해서만 사용됩니다.

2. 수집하지 않는 정보

현재 버전에는 회원가입, 로그인, 온라인 계정, 분석 SDK, 광고 SDK, 광고와 앱 내 결제가 없습니다. Studio Sosim은 앱을 통해 이용자의 이름, 이메일 주소, 전화번호, 주소, 연락처, 사진, 정확한 위치정보, 광고 식별자, 학습 기록 또는 기기 내부 설정을 전송받거나 서버에 저장하지 않습니다.

3. 네트워크 이용과 영어 발음

단어·뜻·그림·화면과 학습 기능은 앱에 포함되어 인터넷 없이 사용할 수 있습니다. 영어 발음은 기기에 설치된 시스템 음성을 사용하므로 영어 음성이 없는 기기에서는 오프라인 발음이 제한될 수 있습니다. 이 개인정보처리방침, 웹의 출처·라이선스 페이지 또는 이메일 링크는 이용자가 직접 선택한 경우에만 외부 웹페이지를 열며 인터넷 연결이 필요합니다.

4. 보관 및 삭제

로컬 학습 데이터는 이용자가 설정에서 모든 학습 기록을 초기화하거나 앱의 저장 데이터를 지우거나 앱을 삭제할 때까지 기기에 보관됩니다. 운영체제와 백업 설정에 따라 기기 백업에 사본이 남을 수 있습니다. 이 정보는 Studio Sosim 서버에 보관되지 않으므로 운영자가 원격으로 열람·복원·삭제할 수 없습니다.

5. 추적·판매·공유

앱은 다른 회사의 앱이나 웹사이트를 가로질러 이용자를 추적하지 않습니다. Studio Sosim은 앱에서 개인정보를 수집하여 판매하거나 공유하지 않습니다. 공개 개인정보처리방침은 GitHub Pages에서 제공되므로 페이지 방문 시 GitHub가 자체 방침에 따라 일반적인 웹 요청 정보를 처리할 수 있습니다.

6. 아동과 보안

앱은 아동을 포함한 이용자에게 연락처나 계정 정보 제출을 요구하지 않습니다. 필요한 경우 보호자가 기기 이용을 지도해 주세요. 학습 기록을 기기 안에만 보관하여 정보 처리를 최소화합니다.

7. 사전·그래픽·라이선스·문의

앱에는 공개 라이선스 사전 자료가 포함됩니다. 출처, 저작자 표시, 변경 내용, 동일조건변경허락, Godot Engine, 글꼴과 자산 고지는 앱의 ‘오픈 라이선스·전체 출처’ 화면에서 확인할 수 있습니다. 탱구는 Studio Sosim의 원작 캐릭터이며 일부 그래픽은 Studio Sosim 제공 참고자료를 바탕으로 AI 보조 도구로 생성·보정한 뒤 Studio Sosim이 선택하고 편집했습니다.
