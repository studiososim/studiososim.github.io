스튜디오소심은 탱구 영어문법공부의 영어 연습 콘텐츠 제공과 서비스 운영을 위해 아래와 같이 정보를 처리합니다.

처리하는 정보와 이용 목적

학습 기록
문제 풀이와 오답, 학습 진행 상태, 즐겨찾기를 해당 브라우저 또는 앱이 설치된 기기에 저장합니다. 이 기록은 학습을 이어서 할 때 사용하며 스튜디오소심의 서버로 전송하지 않습니다.
콘텐츠 요청
오늘의 학습, 연습 문제와 암기 콘텐츠를 가져오는 HTTPS 요청 중 접속 IP 주소, 접속 시각, 요청 경로와 응답 상태 등이 운영 로그에 기록될 수 있습니다. 콘텐츠 전송, 보안 및 오류 대응에 필요한 범위에서 처리합니다. 학습 자료 서버의 데이터베이스에는 공개용 학습 자료를 보관합니다.
문의
이메일로 문의하면 회신 주소와 문의 내용, 이용자가 첨부한 정보를 문의에 답하고 관련 문제를 처리하는 데 사용합니다. 문의를 보낼 때 답변에 필요한 정보만 적어 주세요.

계정, 광고와 결제

처음 공개하는 무료 앱에서는 스튜디오소심 계정을 만들 필요가 없습니다. 광고 표시, 이용자 추적을 위한 별도 분석 및 결제 기능은 제공하지 않습니다. 웹 버전은 기존 공유 범위에 따라 ChatGPT 로그인이 필요할 수 있습니다. 그 로그인은 OpenAI가 처리합니다. OpenAI 개인정보 처리방침

처리 위탁과 국외 처리

콘텐츠 서버 운영
Supabase Pte. Ltd.에 학습 콘텐츠 조회 API 운영, 운영 로그 관리 및 기술 지원을 위탁합니다. 학습 콘텐츠 데이터베이스는 AWS 서울 리전에 있습니다. API 요청 과정에서 운영 로그가 유럽연합 데이터센터에서 처리될 수 있습니다. 이 로그는 콘텐츠 요청이 들어올 때 생성되고, API·데이터베이스 로그의 기본 보유기간은 아래와 같습니다. 장애 대응과 보안 지원에 필요한 경우 싱가포르의 Supabase Pte. Ltd.와 미국의 Supabase, Inc. 등 운영·지원 담당자가 관련 운영 정보에 제한적으로 접근할 수 있습니다. 운영 정보의 처리 범위와 보호조치는 Supabase 데이터 처리 안내에서 확인할 수 있습니다. 수탁자 개인정보 관련 문의는 privacy@supabase.io로 할 수 있습니다.

온라인 콘텐츠 조회 선택
온라인 콘텐츠 요청에 따른 접속정보 처리를 원하지 않는 경우 기기의 네트워크 연결을 끊을 수 있습니다. 이 경우 서버의 새 학습 자료를 가져올 수 없습니다. 위탁 및 국외 처리 관련 요청은 아래 개인정보 문의처로 보내 주세요.

보유 기간과 삭제

  • 학습 기록은 이용자가 지울 때까지 기기 또는 브라우저에 남을 수 있습니다. 앱이나 웹에서 설정 → 기기 학습 기록 지우기를 선택할 수 있습니다. 웹에서는 브라우저 설정에서 이 사이트의 데이터를 지울 수도 있습니다. 앱에서는 기기의 앱 데이터 삭제 기능을 사용하거나 앱을 삭제할 수 있습니다. iOS에서는 앱 정리 대신 앱 삭제를 선택해 주세요.
  • Supabase의 무료 요금제에서 API와 데이터베이스 로그의 기본 보유기간은 1일입니다. Supabase 로그 보유기간
  • 문의 정보는 답변과 관련 업무를 마치면 지체 없이 파기합니다. 법령상 보관 의무가 적용되는 정보는 해당 기간 동안 분리해 보관한 뒤 삭제합니다.

전자 기록은 통상적인 방법으로 복구할 수 없도록 삭제합니다. 네트워크 요청에는 암호화된 HTTPS를 사용하고 서버 관리는 권한이 있는 운영자에게 제한합니다.
