개발자: Studio Sosim · 앱: 탱구의모험-런 (Tanggu Run)

앱에서 바로 삭제

  1. 탱구런을 열고 삭제할 계정으로 로그인합니다.
  2. 설정 → 계정 삭제를 누릅니다.
  3. 확인 창에서 삭제를 확정합니다.

앱을 사용할 수 없는 경우

아래 이메일 버튼으로 삭제 요청을 보내 주세요. 제목은 “탱구런 계정 삭제 요청”으로 하고, 계정 확인을 위해 로그인 이메일 주소와 게임 닉네임을 적어 주세요. 비밀번호나 일회용 로그인 링크는 보내지 마세요.

삭제되는 데이터

탱구런 계정, Supabase 사용자 ID, 이메일 주소, 닉네임, 최고 점수, 순위, 일일 보상 기록, 구매·보상 및 장비 진행 정보, Game Center 연결 정보가 삭제됩니다. 삭제가 끝나면 복구할 수 없습니다. 법령상 보관 의무가 있는 기록은 해당 의무 기간 동안만 별도로 보관될 수 있습니다.

English

Open Tanggu Run, sign in to the account, then choose Settings → Delete Account. If you cannot use the app, email studiososim@gmail.com with the subject “Tanggu Run account deletion request” and include the login email and game nickname. Do not send a password or one-time login link. The account, user ID, email, nickname, scores, ranks, daily rewards, purchase/reward and equipment progress, and Game Center link are deleted and cannot be restored. Records required by law may be retained only for the required period.
