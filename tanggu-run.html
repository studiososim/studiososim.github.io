한국어

시행일: 2026년 9월 4일

Studio Sosim은 탱구런의 계정, 기록 저장과 실시간 순위 기능을 제공하기 위해 다음 정보를 처리합니다.

  • 기기 저장: 최고 거리, 하트, 다이아, 장비·테마·보상, 언어와 소리 설정
  • Supabase 서버: 사용자 ID, 이메일 링크 로그인을 선택한 경우 이메일 주소, 닉네임, 최고 점수, 순위와 일일 보상 기록
  • iOS Game Center 로그인 선택 시: 탱구런 앱 전용 Game Center 식별자와 연결 상태

이 정보는 계정 인증, 게스트 기록 이전, 기록 저장·복원, 실시간 순위, 닉네임 중복 방지, 부정 이용 방지와 안정성 개선에 사용됩니다. 이메일 로그인은 일회용 링크 방식이며 앱은 비밀번호를 수집하거나 저장하지 않습니다. 이 버전에는 광고 SDK와 광고 기능이 포함되어 있지 않습니다.

앱 설정의 계정 삭제에서 탱구런 계정과 이메일, 닉네임, 점수, 순위, 일일 기록 및 Game Center 연결을 영구 삭제할 수 있습니다. 삭제 후에는 복구할 수 없습니다.

일부 이미지, 아이콘, 배경음악 및 효과음 제작에는 생성형 AI 보조 도구가 사용되었습니다. 탱구는 제작자의 오리지널 캐릭터이며 이용자 개인정보를 AI 제작 도구에 입력하지 않습니다.

English

Effective September 4, 2026.

Studio Sosim processes the following information to provide Tanggu Run accounts, saved records, and live rankings.

  • On device: best distance, hearts, diamonds, equipment, themes, rewards, language, and sound settings.
  • On Supabase: user ID, email address when email-link login is selected, nickname, best score, rank, and daily reward history.
  • On iOS when Game Center login is selected: an app-specific Game Center identifier and connection status.

This information is used for authentication, guest-record migration, saving and restoring records, live rankings, nickname uniqueness, abuse prevention, and reliability. Email login uses a one-time link; the app does not collect or store passwords. This version contains no advertising SDK or advertising feature.

Players can use Delete Account in Settings to permanently delete the Tanggu Run account, email, nickname, scores, ranks, daily records, and Game Center link. Deleted information cannot be restored.

日本語

施行日：2026年9月4日

Studio Sosimは、アカウント、記録保存、リアルタイムランキングの提供に必要な情報を処理します。端末にはゲーム設定と進行情報を保存します。SupabaseにはユーザーID、メールリンクログイン選択時のメールアドレス、ニックネーム、最高スコア、順位、デイリー報酬履歴を保存します。Game Centerログイン選択時には、アプリ専用Game Center識別子と連携状態を処理します。

メールログインは一回限りのリンク方式で、アプリはパスワードを収集または保存しません。このバージョンに広告SDKと広告機能は含まれません。設定の「アカウント削除」からすべてのアカウント情報とゲーム記録を完全に削除でき、削除後は復元できません。
